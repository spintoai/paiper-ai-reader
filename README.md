# <img src="https://paiper-ai-public-bucket.s3.ap-northeast-2.amazonaws.com/paiper-ai-v3-reader.png" alt="페이퍼AI 로고" width="40px" height="40px" style="vertical-align: middle;" /> 페이퍼AI

영어 논문을 한글로 번역해 원문과 나란히 읽는 데스크톱 앱입니다. 자세한 소개는 [paiper-ai.com](https://paiper-ai.com)에 있습니다.

## 설치

**[릴리스 페이지](https://github.com/spintoai/paiper-ai-reader/releases/latest)** 에서 최신 버전을 받으세요. 설치한 뒤에는 앱이 스스로 업데이트합니다.

- **Windows**: `.exe` 파일을 받아 실행합니다. 보안 경고가 뜨면 "추가 정보"를 누르고 "실행"을 누릅니다.
- **Mac (Apple Silicon)**: `.dmg` 파일을 받아 열고, 앱을 Applications 폴더로 끌어 놓습니다.

## 사용법

1. 앱을 열고 로그인합니다.
2. 논문 PDF를 올리거나, 웹에서 열리는 논문이면 주소(URL)를 넣습니다.
3. "이 논문 번역하기"를 누릅니다.

번역한 논문은 폰 앱 [페이퍼AI 모바일 뷰어](https://paiper-ai.com/mobile)와 브라우저([app.paiper-ai.com](https://app.paiper-ai.com))에서도 이어 읽을 수 있습니다.

## 요금

논문 한 편에 10 크레딧이 듭니다(아주 긴 논문은 더 듭니다).

- **무료 체험**: 가입하면 30 크레딧(논문 3편)을 드립니다.
- **프리미엄 플랜**: 월 20,000원, 매달 150 크레딧. 남은 크레딧은 다음 달로 넘어갑니다.
- **선불 패스**: 한 달 20,000원, 매달 120 크레딧. 자동 결제 없이 사고, 선물할 수도 있습니다.

자세한 조건은 [요금 안내](https://paiper-ai.com/plan)에 있습니다.
